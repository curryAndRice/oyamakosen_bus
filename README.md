# 家への誘い

**小山高専 ⇔ 小山駅東口の「次のバス」を、開いた瞬間に。**

https://curryandrice.github.io/oyamakosen_bus/

学校終わりに「次のバス、いつ？ 今どこ？」となったら、これを開くだけ。
おーバス（高岳線・城東中久喜線・桑東部絹路線）の次の便が出て、タップすれば、おーバスLiveでそのバスの現在地が見られます。

## できること
- **次に乗れるバスが、開くだけで分かる。** 3路線をまとめて、発車時刻順に表示します。直前に出た1便と、次の5便です。
- **現在地が1タップで見られる。** 便をタップすると、おーバスLiveの現在地ページへ直接移動します。路線とバス停を選ぶ手間はありません。
- **方向は自動で切り替わる。** 午前は駅→高専、午後は高専→駅です。ボタンでも切り替えられます。
- **平日と土日のダイヤに対応。** 桑東部絹路線の土日・年末年始（12/29〜1/3）の運休も反映しています。
- **時刻を指定して調べられる。** 「帰りが遅くなりそう」なときの確認に使えます。
- **友達を誘える。** ページ下部の「友達を“家へと誘う”」ボタンで、LINEなどに共有できます。

## 使い方
1. 上のURLを開く（スマホのホーム画面に追加しておくと便利）。
2. 乗りたい便をタップ。
3. おーバスLiveで、バスの現在地を見る。

アプリを開いてから、**1タップ**で現在地に届きます。

対応ブラウザは、Android Chrome、Windows Edge、iPhone Safari、Android Firefox の各最新版です。

## 後輩のみなさんへ：このアプリを受け継いでくれる人を探しています

このアプリは、「毎日使うバスの確認を、極限まで楽にしたい」という、小山高専生のわがままから生まれました。
作った人はいつか卒業します。でも、バスは走り続けるし、ダイヤも変わります。**受け継いでくれる後輩がいないと、このアプリは止まってしまいます。**

### 受け継ぎは、思っているより軽い
- **ビルドもフレームワークもありません。** 素の HTML・CSS・JavaScript だけです。`npm install` は要りません。
- **1ファイル1仕事。** どこを直せばいいか、すぐ分かる作りです（[ファイル構成](#ファイル構成)）。
- **時刻表はデータだけで直せる。** プログラムを読まなくても、`data/timetable.json` を書き換えるだけでダイヤ改正に対応できます。
- **自動検査つき。** 書き間違えても、`python tools/check_timetable.py` が教えてくれます。
- **Python が入っていれば、1行で動く。** [ローカルでの動かし方](#ローカルでの動かし方)を見てください。

### やってみると得られるもの
- 自分たちの毎日の役に立つものを、**自分の手で運用する経験**。
- 実際に使われているサイトを、公開・保守するときの感覚（公開、実機確認、ダイヤ改正への対応）。
- デジタル庁デザインシステムに沿った、アクセシブルな画面づくり。
- 「3タップ以内」「100ms以下」といった目標に向けた、速度とUIの追い込み。
- 就活やポートフォリオに書ける、**ちゃんと使われているアプリ**。

### 仕事の中身
| 頻度 | 仕事 | 目安 |
|---|---|---|
| ダイヤ改正のとき | 時刻表PDFを差し替え、`data/timetable.json` を更新 | 1〜2時間（[手順](#ダイヤ改正のとき)） |
| たまに | 学校行事（文化祭など）の臨時便を `extraTrips` に追加 | 数分 |
| 気が向いたとき | 改善・新機能（下記） | 自由 |

**こんな改善が待っています：**
- 臨時便（文化祭シーズンの追加便）の登録
- Service Worker によるオフライン対応（いまは旧SWの後始末用ファイルがあるだけ）
- 表示速度の実測と改善（目標: 再訪時もタップ後も 100ms 以下）
- おーバスLiveのリンクが切れていないかの定期チェック
- ほかのバス停・路線への対応

### 関わり方
- **まずは使ってみて、気づいたことを [Issues](https://github.com/curryAndRice/oyamakosen_bus/issues) に書いてください。** 「ここが見にくい」「この便が違う」といった一言で大歓迎です。
- ダイヤの間違いを見つけたら、その場で `data/timetable.json` を直して、[Pull Request](https://github.com/curryAndRice/oyamakosen_bus/pulls) を送ってもらえると助かります。
- 「受け継ぎたい」と思ったら、リポジトリをフォークして、気軽に始めてください。

プログラミングの経験は問いません。時刻表のデータを直すだけでも、立派な「受け継ぎ」です。

## ローカルでの動かし方
`index.html` をダブルクリックしても動きません（ES modules と `fetch` を使っているため）。サーバ経由で開いてください。

```
python -m http.server 8123
```

ブラウザで http://localhost:8123/ を開きます。終了は `Ctrl + C` です。

- 8000番が使われているPCでは、上のようにポート番号を指定してください。
- スマホ実機で確認するときは、`--bind 0.0.0.0` を付けて起動し、`http://<PCのIPアドレス>:8123/` を開きます（同じWi-Fiにつなぐ）。
- 詳しい手順と確認項目は [CHANGES.md](CHANGES.md) にあります。

## ダイヤ改正のとき
1. 小山市の公式時刻表PDFを、ルート直下の `takaoka.pdf`・`johtoh.pdf`・`kuwatohbu.pdf` に差し替える。
2. [data/timetable.json](data/timetable.json) を更新する（書き方は [data/README.md](data/README.md)）。
3. `python tools/check_timetable.py` を実行して、`OK` と出ることを確認する。
4. ローカルで動かして、平日と土日、午前と午後の表示を見る。

## ファイル構成
1ファイルが1つの仕事だけをします。

```
index.html               マークアップのみ
css/tokens.css           デザイントークン（色・余白・サイズ）
css/app.css              部品とレイアウト
js/calendar.js           平日/土日の判定、運休期間
js/timetable.js          時刻表の読み込みと、便の抽出
js/view.js               画面への描画だけ
js/share.js              「友達を誘う」ボタン
js/main.js               状態管理と、イベントの結線
data/timetable.json      時刻表の正本
tools/check_timetable.py 時刻表データの検査
img/                     アイコン
archive/                 旧バージョン（成長記録。リンクはしていません）
```

## 大事にしていること
- **3タップ以内**で、おーバスLiveの現在地まで行ける。
- **再訪時の表示も、タップ後の遷移も 100ms 以下**を目指す。外部スクリプトは増やさない。
- **スマホで使いやすい**こと。縦向きでも、文字が変なところで折り返さない。
- デザインは、**デジタル庁デザインシステム**の考え方に沿う（読みやすさ、押しやすさ、フォーカス表示）。
