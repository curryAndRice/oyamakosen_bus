# 時刻表データ (timetable.json) の書き方

ダイヤ改正時は、このフォルダの `timetable.json` だけを直せば画面に反映される。

## 全体
| キー | 内容 |
|---|---|
| `revision` | 改正年月日（表示用） |
| `routes` | 路線の定義。路線名・路線色・運行ルール |
| `lines` | 路線×方向（×回り）ごとの時刻表 |
| `extraTrips` | 臨時便（文化祭など）。日付指定 |

## routes
- `color` … 路線のイメージカラー（便の左の帯に使う）。
- `tagColor` … 路線名タグの背景色。白文字を載せるので、白とのコントラスト比 4.5:1 以上になるよう `color` を暗くした色にする。
- `runs` … 運行する曜日区分。`weekday`=月〜金、`weekend`=土・日。**祝日は区別しない**（月〜金の祝日は `weekday` 扱い）。
- `suspend` … 運休期間のリスト。`{"from": "12-29", "to": "01-03"}`（`MM-DD`、年またぎ可）。
- `pdf` … ルート直下の小山市公式時刻表PDF。

## lines
- `direction` … `toStation`（高専→駅）または `toSchool`（駅→高専）。
- `label` … 同一路線で回り方向が違う場合の表示ラベル（桑東部絹路線のみ）。
- `from` / `to` … 乗るバス停 / 降りるバス停（表示用）。
- `link` … おーバスLiveの深いリンク（乗るバス停のもの）。
- `trips` … `["発車", "到着"]`、または `["発車", "到着", "weekday"]`。時刻は `"HH:MM"`（24時間表記）、発車時刻の昇順。
  - 第3要素 `"weekday"` / `"weekend"` を付けると、その曜日区分のみ運行する便になる（例: 城東中久喜線の1・33便は `"weekday"`）。

## extraTrips
```json
{ "line": "takaoka-toSchool", "dep": "14:00", "arr": "14:13", "dates": ["2026-11-07"] }
```
`line` は `lines[].id`。`dates` は `YYYY-MM-DD`。指定日にだけ、通常の便に混ざって表示される。

## 確認方法
`python tools/check_timetable.py` で、時刻の昇順・書式・到着が発車より後であること等を検査できる。
